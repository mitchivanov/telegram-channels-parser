# Запуск одной командой

Теперь вы можете запустить всю систему одной командой:

```bash
docker compose up -d
```

## Что происходит:

1. **Все контейнеры запускаются сразу**
   - Парсер начинает инициализацию
   - Channel-sync запускается и ждет

2. **Channel-sync автоматически ждет сессию**
   - Проверяет наличие файла сессии каждые 30 секунд
   - Отправляет уведомление что ждет авторизации
   - Не спамит сообщениями

3. **После авторизации парсера**
   - Channel-sync обнаруживает сессию
   - Начинает синхронизацию с Google Sheets
   - Отправляет отчет о результатах

## Мониторинг

```bash
# Следите за запросом кода при первом запуске
docker compose logs -f notifications-bot

# Статус синхронизации
docker compose logs -f channel-sync

# Все логи
docker compose logs -f
```

## Преимущества:

✅ Не нужно запоминать порядок запуска
✅ Channel-sync не падает без сессии
✅ Информативные уведомления о статусе
✅ Не спамит повторяющимися ошибками
